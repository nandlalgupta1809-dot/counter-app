# counter-app
A simple and interactive counter app built with HTML, CSS, and JavaScript, featuring increment and save functionality.

 Counter App

A simple and interactive counter application built using **HTML, CSS, and JavaScript**. The app allows users to increment a counter and save the current count as an entry.

 Features

 Increment the counter
 Save the current count
 Display previously saved entries
 Simple and clean user interface
 Built with vanilla JavaScript

 Technologies Used

 **HTML5** — Structure
 **CSS3** — Styling and layout
 **JavaScript** — Functionality and interactivity

 

 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/nandlalgupta1809-dot/counter-app.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it!
